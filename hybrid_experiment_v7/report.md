# v7 障碍安全绕行点偏移 PPO 短训报告

v7 让 PPO 学习二维绕行点偏移，但在使用前把偏移投影到安全集：目标点须在保守边界内，
且小球到目标点的直线段须避开全部膨胀障碍物；不安全则二分收缩偏移。零偏移即 v3 规则。
本实验不修改物理参数。
