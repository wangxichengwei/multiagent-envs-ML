# 200局统一评估

用途：检查点选择与基础速度控制器对照，属于验证集；不能作为选择模型后的独立最终测试集。

- 随机种子：20261023；200组初始条件保存在scenarios.json。
- 所有方法使用同一组初始条件、固定障碍物和300步上限。
- 初始位置采样范围[-0.8,0.8]，两两间距以及到障碍物中心的间距至少0.25。
- PPO检查点：3400、4000、5200、7400、10000；关闭探索，加载原模型，不更新参数。
- 每局从800×800 RGB图像缩放到400×400检测位置，使用相同VisualState编码器。
- 真值仅供环境物理、重置及结局判定使用，不供策略或控制器决策使用。
- velocity_direct：朝终点生成目标速度，采用8倍速度误差作为加速度指令，范数限幅1。
- velocity_path：同一速度控制器，目标改为可见性图的下一绕行点；路线切换设置0.02代价滞回。
- 目标速度上限0.25；接近目标点采用sqrt(2*0.7*max(distance-0.025,0))限制速度。
- 路径图沿用PathReward的0.09膨胀半径和16个绕行节点，未按本验证集结果调参。
- 两个基础控制器均未使用捕食者预测、安全筛选或PPO修正。
- 为减少显示开销，关闭垂直同步并省略翻屏；在10个运动状态检查过RGB逐像素一致。
- 方法并行运行，各自独立环境；逐局写入jsonl，支持中断后跳过已完成局。

运行：conda activate multiagent，然后python evaluate_200.py。
查看汇总：python evaluate_200.py --summary。
summary.csv/json含结局次数、成功率、Wilson 95%区间及成功平均步数。
